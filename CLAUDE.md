## What this is

Body pose for the Argus suite: whole-body keypoints, pose embeddings, diversity and coverage metrics, and ControlNet pose conditioning (:8110)

Shared code — the target taxonomy, wire-schema versioning, and the local/remote model contract — lives in **argus-cortex**; import it rather than re-implementing.

## Layout

`src/argus_puppet/` — the package. Key modules:

- `__init__.py` — version shim (`__version__` from `hatch-vcs`).
- `skeleton.py` — the COCO-WholeBody 133 layout as data: names, part slices (`BODY`, `FEET`, `FACE`, `LEFT_HAND`,
  `RIGHT_HAND`, `PARTS`), `Joint` indices, limbs, `FLIP_PAIRS`/`FLIP_PERMUTATION`/`flip_horizontal`, and the OpenPose-18
  convention (`to_openpose18`, limbs, colours, hand edges). Pure numpy, no I/O. Index keypoints through it, never by
  bare numbers elsewhere.
- `models.py` — the Pydantic v2 wire contract (`puppet_version`, `PUPPET_VERSION`). Only top-level payloads
  (`PoseResult`, `PoseSetStats`, `PoseSetComparison`, `PoseLibrary`, `Health`) subclass the versioned base. Add a field:
  bump the minor and note it in the version comment; rename or remove one: a new major. Then `make schema` and commit
  `schema/puppet-wire.schema.json`. Sidecars are `<stem>.pose.json` (`SIDECAR_SUFFIX`, `sidecar_path`).
- `registry.py` — the pinned model table (`PinnedModel`, `MODELS`, `DEFAULT_*`/`LIGHT_*`, `model_ref`). Data only; a new
  model needs a permissive licence and its sha256, or `tests/test_must_never.py` fails.
- `config.py` — `Settings.from_env()` (`ARGUS_PUPPET_*`), `ConfigError`, and `DEFAULT_PORT` (the only code constant for the port;
  it may change).
- `runtime.py` — ONNX Runtime plumbing: `providers(device)` (CUDA only when ORT really has it), the capped CUDA arena
  (`kSameAsRequested`, `Settings.gpu_mem_limit_mb` else 1024 MB per session), `check_model` (size + SHA-256 against the
  registry, hash memoised by path/mtime/size) before any load, cached `load_session`, `ModelUnavailable` (ends with the
  `argus-puppet models fetch` hint). onnxruntime is optional: never import it at module level.
- `estimator.py` — the numpy + ORT + Pillow pipeline (YOLOX raw head, then RTMPose SimCC; matches rtmlib to ~0 px).
  `Estimator` protocol (`estimate(image) -> list[PersonPose]`, `provenance()`), `OnnxEstimator`, and
  `get_estimator(settings, ...)`, which tests monkeypatch so the suite runs with no model files.
- `primary.py` — the primary subject: curator's `area * (0.5 + 0.5 * det_score)`, or the body best matching a
  primary-face hint (mean of IoU and face coverage), falling back to area x score.
- `gpu.py` — leases from argus-iris via `argus_cortex.gpu` (kind `pose`, figures kept in step with `gpu-tenant.yaml`
  by `tests/test_gpu.py`); none on CPU; `parse_priority` for `X-Argus-Priority`; `folder_lease` holds one lease per
  folder run and hands it back on `should_yield()`.
- `extract.py` — the library API: `pose_image(bytes|path) -> PoseResult`, `pose_folder(root) -> Iterator[ImageOutcome]`
  (atomic sorted-key sidecars, skip-existing, `sidecar_collision`, unreadable images reported), `scan() -> ScanSummary`.
  Images decode through `argus_cortex.limits.open_image` with EXIF orientation.
- `weights.py` — `models list|fetch|verify`: downloads via `argus_cortex.net.fetch` from `ALLOWED_HOSTS` only,
  archive sha256 then the one zip member (never `extractall`), onnx sha256 + size, atomic write.
- `cli.py` — Typer app; entry point `argus-puppet` (`[project.scripts]`): `pose`, `serve`, `models`, `schema`, `version`.
  One app: add commands with `@app.command()`; run `make docs` after.
- `server/app.py` — `create_app(settings, *, estimator=, coordinator=)` (and a lazy module-level `app` for uvicorn):
  `GET /health`, `POST /pose` (writes nothing; inference via `asyncio.to_thread`, bounded concurrency -> 503), `POST
  /pose/scan` (the one write; `path` fenced under `Settings.data_root` with `safe_join`). `install_guards` wires
  origin guard, then read-only guard, then CORS outermost. Shared state for new routes: `app.state.puppet` (`AppState`).
- `gpu-tenant.yaml` (repo root) — the argus-iris tenant manifest (kind `pose`); `tests/test_gpu_tenant.py` validates it.

## Commands

```bash
make install   # uv venv + editable install with the dev,server,cli,cpu extras
make schema    # regenerate schema/puppet-wire.schema.json (CI checks it)
make test      # pytest --tb=short -q
make lint      # ruff check + format --check (pinned ruff 0.15.16)
make format    # ruff format + --fix
```

Run one test: `uv run --no-sync pytest tests/test_x.py::test_name -q`.

## Conventions & gotchas

- **Versioning is git-tag-derived** (`hatch-vcs`). Never hand-edit a version; `src/argus_puppet/_version.py` is generated (gitignored). Tag `vX.Y.Z` to release.
- **`src/` layout, `py.typed`, Pydantic v2, `structlog`.** Ruff line-length 120; keep it clean (`make lint`) before committing.
- **Any endpoint that does something is a boundary.** There's no auth by default — treat reaching the port as host access. Gate state-changing routes behind the shared read-only / origin guards, and fence any caller-supplied path under a configured root.
- Wire schemas (if any) are checked in and verified in CI — regenerate and commit when the types change, don't let the committed copy drift.

## Branches

`dev` is the default branch and the base for every PR. Cut feature branches from `origin/dev` and bring them up to date by merging `origin/dev`, never `main`. Never push work to `main` or open a PR against it, except the release PR from `dev`: `main` must never be ahead of `dev`, with one exception. A release fast-forwards `main` to a `dev` commit that passed CI (`git push origin origin/dev:main`), then tags it. If `main` is protected, the release is a reviewed PR from `dev` into `main`, and merging it leaves a merge commit on `main` alone. That merge commit is the one exception to the rule: it leaves `main` one commit ahead of `dev` with an identical tree. Leave it there and don't merge `main` back into `dev`. Anything else on `main` that `dev` lacks is a mistake (`git diff origin/dev origin/main` must be empty). Once `main` carries such a commit it can't be fast-forwarded, so later releases are PRs too.

## CI / release

CI runs via the shared [`argus-ci`](https://github.com/smk762/argus-ci) reusable workflow. `docs.yml` runs its `docs-check` on every push: published docs (`README.md`, `docs/**/*.md`) must hold no private IPs, home/server paths or personal emails (use placeholders like `<GPU_HOST>`), and `docs/cli.md` must match the CLI — run `make docs` after changing a command. Release publishes to PyPI (OIDC trusted publishing) + GHCR on `v*` tags. Run `copier update` to pull template (CI/release/tooling) changes.
